# Dictionnator

Entrez un mot puis cliquez sur Définir : les définitions proviennent du dictionnaire français Kaikki/Wiktionnaire enregistré dans data/dictionary.sqlite3. Aucun modèle ni accès à Internet n’est nécessaire pour chercher. Les formes conjuguées renvoient au mot de base et les fautes de frappe proposent des mots proches. Le lien de source ouvre l’article du Wiktionnaire seulement si vous cliquez dessus. Voir data/LICENCE.md et data/SOURCE.json pour la provenance.
