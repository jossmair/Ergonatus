# Sablier vert de Lector

Généré avec l’outil intégré ImageGen le 18 octobre 2026. Actifs du projet : `hourglass-green.png` (proposition avec sable) et `hourglass-frame.png` (cadre vide utilisé dans l’application). Les PNG conservent leur transparence.

Prompt initial : « Create one elegant luminous green hourglass, centered, isolated on a genuinely transparent background. A polished glass hourglass with flowing fine emerald and soft apple-green sand, dark forest-green metallic frame, delicate teal energy filaments matching futuristic crystalline green desktop orbs. Calm, reassuring, gentle studio lighting, highly readable silhouette at 120 pixels. Symmetrical front view, generous transparent margins, single hourglass only. No words, no letters, no logos, no background, no square panel, no watermark. »

Prompt d’édition : « Preserve its elegant green metallic frame, glass shape, frontal symmetrical view, proportions and green color family. REMOVE ALL SAND and all particles from inside both glass chambers so both chambers are EMPTY and visually clear. Make all surroundings truly transparent. Leave empty clear transparent space in both glass chambers so animated green sand can be drawn into them later by software. Single front-view hourglass centered with generous transparent margins. No text, no extra objects, no tilted camera. »

Animation native : `shared/ui/reading_busy.py`. Sable supérieur qui se vide, grains qui tombent, tas inférieur qui monte, retournement de 180° en fin de cycle. Le sablier mesure 64 × 96 pixels logiques dans un panneau de 132 × 142 pixels. Le mode sans animations conserve une image fixe. Le panneau n’accepte ni le focus ni les clics.
