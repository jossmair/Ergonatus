# Tablinator

Toutes les tables de 1 à 12 sont réunies dans une grille compacte de 144 cartes, sans défilement. Cliquez sur une case pour retourner le calcul et voir son produit ; cliquez de nouveau pour revenir. La flèche circulaire réinitialise toutes les cases. Un clic sur l’Orb affiche ou masque le widget déplaçable et redimensionnable ; double-clic : fenêtre principale. Échap ferme le widget. Le curseur Fond règle l’opacité du panneau, les cartes restent lisibles. Aucun plein écran.
