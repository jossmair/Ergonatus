# Fonds Fortinatus

Deux images créées avec l’outil imagegen intégré, le 16 octobre 2026, puis intégrées dans l’application. Les contrôles restent natifs et éditables.

- `main-v1.png` : fenêtre principale, 1536 × 1024.
- `dialog-v1.png` : options et modification d’une touche, 1024 × 1536.

Les images sont recadrées proportionnellement au redimensionnement. Les panneaux des commandes restent sombres pour garder le texte lisible.
