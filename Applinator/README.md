# Applinator

## Choisir les raccourcis du widget

Le logiciel détecte les applications du menu Démarrer, les raccourcis du Bureau et les applications Windows/Store. Elles sont classées par usage : Internet, Bureautique, Communication, Création et médias, École et accessibilité, Utilitaires. Ergonatus représente la suite ; ses satellites ne sont pas ajoutés séparément.

**Cochez les applications à afficher dans le widget.** Les autres restent disponibles dans le catalogue. Utilisez la recherche ou les catégories pour les trouver, puis glissez les lignes pour régler leur ordre. Les choix sont mémorisés immédiatement. Tout décocher vide uniquement le widget.

Le tri retire du catalogue les aides, désinstalleurs, documents techniques, outils d’administration, variantes de dépannage et doublons courants. Aucun programme n’est supprimé ou désinstallé. Un logiciel portable ou un outil masqué reste ajoutable avec Ajouter un logiciel ou en glissant son raccourci dans la fenêtre.

## Utiliser le widget

Un clic sur l’Orb affiche les seuls raccourcis cochés. Cliquez une application pour la lancer et masquer le widget. Un clic sur le fond, l’Orb ou Échap le masque également. Double-clic sur l’Orb, clic droit > Configurer mes raccourcis, ou l’engrenage du widget pour revenir à la sélection.

Le curseur Fond du widget règle la transparence ; les tuiles restent lisibles. Icônes Windows natives lorsqu’elles sont disponibles, pictogrammes SVG originaux par usage pour les autres. Aucun téléchargement ni service distant.

Formats de fichiers ajoutables : EXE, LNK, APPREF-MS, URL, BAT, CMD, COM et MSC. Windows effectue le lancement avec ses associations habituelles. Les applications Store utilisent leur identifiant Windows validé. Le logiciel ne copie, déplace ni désinstalle aucune application.

La migration de l’ancienne version conserve le catalogue filtré et laisse uniquement Ergonatus coché ; vos nouveaux choix sont ensuite conservés. Les anciennes données Dictator restent sur le disque et ne sont pas utilisées. Les profils du hub conservent favoris et position de l’Orb lors du remplacement de Dictator par Applinator.

Widget affiné : suppression du compteur/texte inférieur, fond anthracite dégradé, ombre douce, largeur adaptée au nombre de raccourcis, tuiles discrètes sans gros contours, recherche affichée à partir de neuf raccourcis et commandes d’angle sans cadre. Les icônes Windows sont récupérées directement auprès du système ; les choix et la transparence existants restent mémorisés.
