# Communicator 0.4 — interface simple

Choisissez une situation puis une carte : son message apparaît immédiatement dans la zone d’écriture, sans son. Vous pouvez aussi saisir votre propre texte. 108 messages, situations accessibles directement, École en deuxième catégorie. Six émotions restent accessibles dans la colonne de droite.

Le haut-parleur intégré dans chaque carte lit uniquement cette carte, sans modifier le message écrit. Le haut-parleur en haut lit le texte de la zone d’écriture. Le carré arrête la voix ; les petites commandes permettent d’annuler, effacer ou montrer le message en grand.

Le panneau Personnaliser et toutes ses options sont retirés : aucun réglage d’assemblage, de favoris ou de voix, aucun bouton d’import/export ou de gestion des cartes dans cette fenêtre. Une carte affiche toujours un seul message ; le texte libre reste modifiable. Le choix de voix précédemment enregistré est conservé, sinon la voix féminine locale est utilisée. Les cartes personnelles et favoris déjà enregistrés ne sont pas supprimés. Leurs fonctions internes de gestion sont conservées dans le code mais ne sont pas accessibles depuis cet écran simplifié.

Le message et son annulation restent uniquement en mémoire pendant la session. Aucun son automatique, compte obligatoire ou envoi Internet. Symboles emoji Windows accompagnés de textes, sans banque de pictogrammes spécialisée ni suivi du regard annoncé.

Lancer runtime/Communicator.exe ou le hub. Fenêtre déplaçable et redimensionnable. Données locales : %LOCALAPPDATA%/Ergonatus/communicator/.

Icône vocale : ../assets/communicator/speak.png ; prompt : ../assets/communicator/GENERATION.md. Validation : ../docs/VALIDATION_V2.md.

Recherche retirée. Les situations de départ affichent leurs 12 cartes en entier sur trois colonnes et quatre rangées, sans zone défilante. La hauteur minimale de la grille empêche de couper la dernière rangée. Pour les ensembles personnalisés historiques dépassant 12 cartes, des boutons Précédent/Suivant apparaissent plutôt qu’une barre de défilement.
