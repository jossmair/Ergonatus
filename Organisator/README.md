# Organisator

Choisissez École primaire, Collège, Professionnel ou Particulier, cochez les dossiers utiles puis cliquez sur **Créer sur le Bureau**. Les dossiers reçoivent des icônes colorées, visibles également dans l’Explorateur Windows.

Déposez les documents dans **À classer**, ou directement à la racine de cet espace. Organisator affiche leur aperçu et propose un rangement selon leur nom et leur contenu. Vérifiez les cases et cliquez sur **Classer la sélection**. Le tri automatique, facultatif, ne déplace que les propositions les plus sûres et attend que le fichier soit stable.

Aucune suppression ni écrasement : un nom déjà présent reçoit un suffixe. **Annuler le dernier tri** remet les fichiers à leur place si leurs données n’ont pas changé. Aucun dossier extérieur à cet espace n’est trié.

Lancer `runtime/Organisator.exe` ou le lanceur CMD de ce dossier. Gardez les ressources partagées de la suite. Détails et limites : [documentation](../docs/ORGANISATOR.md).
