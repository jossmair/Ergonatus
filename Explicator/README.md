# Explicator

Un clic sur l’Orb lance une capture de zone, un double-clic ouvre la fenêtre. Échap annule la capture. Le texte reconnu reste modifiable. Choisissez Primaire, Collège ou Lycée, puis demandez jusqu’à trois indices de méthode. Le prompt interdit de fournir la solution ; les réponses restent générées par un LLM.
